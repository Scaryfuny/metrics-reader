Privacy policy

Last updated: 19 October 2026.

What the tool accesses

Metrics Reader asks Google only for read-only access: youtube.readonly and yt-analytics.readonly. It reads statistics of the channel that belongs to the account that authorizes it: views, watch time, audience retention, likes, comments and subscriber counts.

Where the data goes

The data is saved only on the authorizing user's own computer. It is not sent to any server of ours, not shared with anyone, not sold and not used for advertising. The tool cannot change anything on YouTube.

This website

This website uses no cookies, no analytics and no tracking.

Google API Services

The use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

How to remove access

Access can be removed at any time at myaccount.google.com/permissions.
